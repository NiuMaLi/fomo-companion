## 小额闭环示例

仅在报价和行情允许时，买入约 9U SOL，确认后创建卖出当前持仓 30% 的单；成交核对后再创建剩余持仓 50% 的单；最后卖出剩余全部。

不计价格与费用变化，金额约为 2.70U、3.15U、3.15U。每一步重新创建数量快照并检查实际报价，该示例不保证任意行情下都可完成。

买入、卖出、限价触发的实盘验证复用同一测试仓位，不为测试覆盖率反复扩大仓位。价格穿越、跳空、亏损、双侧同时触发等优先用模拟行情验证，不人为制造亏损。

## 必要的确定性测试

| 场景 | 必须验证 |
| --- | --- |
| 买入限价／卖出限价／止损 | 三种价格比较方向正确，等于目标价的边界一致 |
| 目标价与涨跌幅 | 正负值、成本缺失、非法零值、行情更新时固定目标价 |

| 崩溃与恢复 | 认领、签名持久化、广播前后各断点，不重复创建未知结果交易 |
