# 安装与使用 v0.8.0

## 安装

1. Chrome 扩展管理页开启开发者模式。
2. 加载 `.output/chrome-mv3`，或解压发布 ZIP 后加载含 manifest.json 的目录。
3. 已安装的扩展应更新原目录并重新加载，保留扩展 ID 和数据库；避免卸载重装。
4. 刷新已登录的 FOMO 页，点击工具栏的插件图标打开侧边栏。

权限包含 FOMO 和飞书域名。Token 和 Cookie 留在 FOMO 页面内，无需手动粘贴。

## 界面语言

面板右上角选择“中文”或“English”，立即切换界面、状态、提示及历史日志的显示语言；选择保存在本地，重新打开仍使用上次语言。首次默认中文。新发送的飞书成交／告警消息也使用当前语言；已经发送的消息不更改。原始平台错误和未知消息保留原文，币种名称、地址、数值与哈希保持原样。

语言设置独立保存，不修改监控／真实下单开关、订单或通知配置。v0.6.0 → v0.7.0 保持数据库版本 4，无需清数据；旧设置缺少语言字段时补中文默认值。

## 条件单与真实持仓

行情跟随当前 `https://fomo.family/tokens/{network}/{address}`。已识别 ethereum、bnb、monad、robinhood、arc、base、solana，未知网络不猜测。SOL 只是开发下单测试指定币种。

点击主价格 K 线可回填目标价格，界面显示较现价／成本的涨跌幅。卖出支持 30%、50%、100% 和自定义比例，数量以建单时真实余额固定并预留。插件不设最低买卖金额；必须大于零并满足代币精度、真实余额和防超卖校验，平台在报价阶段仍可能拒绝小额交易。

真实下单关闭时仅保存和监控。价格触达记录“曾达到目标”，仍可取消，不增加持仓、不生成模拟成交，也不通知成交。浏览器关闭或 FOMO 页面离线时停止监控。

钱包能力就绪后，可开启“真实下单”，再开启自动监控。真实执行按 FOMO 报价选择 Solana、Relay 或 Mobula 路线，覆盖平台当前七个现货网络的币对。买入从平台统一 Solana USDC 资金池支付，卖出换回该资金币；这不是目标资产限制。EVM 来源使用网站原生智能账户签名／UserOperation 提交，Solana 来源使用单次底层执行接口，支持跨链及平台 Jito 路线。钱包可能要求本人确认。无报价、流动性／余额不足或平台拒绝时照实失败，不承诺任意代币必能成交。

最大滑点移至“创建条件单”，每笔独立配置，可填大于 0 且不超过 5% 的数值，最小步进 0.01%。留空或 0 表示不启用插件滑点保护，不回退旧全局设置，也不向 FOMO 传自定义 slippageBps；平台自动生成的交易仍可能有内置成交限制，插件不会改写已签名交易中的最小输出。设置页不再提供全局滑点。

启用滑点保护时，限价／止盈按含滑点的保守报价检查目标价，止损按触发实时价与所填滑点检查；关闭时，限价／止盈仍检查预期报价是否满足目标价，止损不再额外做报价偏离上限检查。价格影响超过 5% 的独立校验保留。目标价不保证实际成交价格。附带止盈止损继承父买单的滑点配置。订单卡片及新日志快照可查看滑点状态。

切币后滑点输入清空，不默认开启。v0.8.0 不归档订单或重置开关；旧订单未记录逐单滑点时按关闭处理，旧全局配置不再参与执行。历史日志没有记录滑点时显示“未记录”，不推断其历史配置。

每条条件单显示自身资产的当前价和“实时／已过期／待更新”；改变当前 K 线不会更改旧单资产。留在同一个 FOMO 标签页内切换到其他币种或发现页，待触发单仍独立订阅行情。关闭 FOMO 页、浏览器或电脑休眠时不能保证执行。

**本版尚未实际签名、广播或完成真实买卖验收。** 已验证真实报价、交易预检、原生多链接口结构与确定性执行测试。首次实盘请本人确认 SOL 测试持仓与最小金额，建议约 4U 买入后再核对卖出，测试持仓合计≤10U。独立服务、原生历史分页和长期值守仍未验收。附带互斥保护组已实现并通过确定性测试，尚未进行实盘验收。

v0.4.0／v0.5.0 升级至 v0.6.0 保持数据库版本 4，不归档订单、不重置开关或通知配置。

此前升级 v0.4.0 会归档 v0.3 的待触发单，关闭监控和真实下单。更早版本升级仍会移除模拟仓位。历史模拟结果标记为旧版记录，不能转为实盘。

## 买入附带止盈止损

限价买入表单可分别勾选附带止盈和附带止损；支持绝对目标价、相对买入限价的涨跌幅快捷填入，以及 30%／50%／100%／自定义卖出比例。止盈价应高于买入限价，止损价低于买入限价。保护价是固定价格，不随实际成交价自动重算。切币会清空保护设置。

无持仓时也可保存。父买单未确认时仅保存计划，不创建可执行卖单；买入确认与子单创建在同一数据库事务中完成。按本笔实际成交数量计算、向下按代币精度取整，不使用既有全部持仓；不足一个最小单位的子单标记阻止并写入日志。

两侧共享预留，按较大数量计一次。一侧成交后，另一侧自动取消，**即使成交侧只卖出 30% 也会取消另一侧**；余仓需要另行设置。准备、签名、提交或结果未知期间阻止其他执行；确认失败或签名前终止不会伪造对侧成交。可单独取消仍在等待的保护单，另一侧保留。父单失败或取消不启用保护。

## 日志

“日志”页按全部／操作／交易／系统筛选，展示时间、级别、币种、订单短编号。交易日志记录本插件条件单的创建、触达、签名、提交、回执核对与取消，不等于 FOMO 全量成交历史。操作、系统异常和日志可持久保存，面板最多显示最近 500 条。可导出当前可见账户的脱敏订单和日志；通知地址和认证凭据不进入导出。

每条关联订单的日志可展开“订单详情”，查看完整订单编号、币对／网络／代币地址、订单类型与事件时状态、目标价、事件价、金额或数量／比例、成交价格／数量／价值、确认核对时剩余仓位、关键时间、附带保护计划、关联订单／互斥组及失败原因。已产生哈希时显示完整哈希和对应来源网络的浏览器链接；未产生或无法取得的字段不伪造为零。

新日志保存独立事件快照，后续成交或取消不会改写历史状态。旧日志没有快照时，若订单仍存在，显示其当前资料并明确标注；订单已不可用则说明无详情，不能还原旧事件时的数据。详情默认折叠，可用键盘展开。

日志导出使用 schemaVersion 2，包含已有事件快照、原始 message 及当前语言的 displayMessage，并记录导出语言／时间。旧日志不会被补写为伪造的历史快照。账户 ID、认证凭据和通知地址不进入导出。

## 飞书通知

设置页分别填写两套自定义机器人 Webhook 并保存，可使用不同机器人：

- 订单通知：只用于已确认成交。已接入链上成交核对，包含币对、方向、实际成交价格／数量／USDC 价值、确认核对时同币剩余数量及哈希。直接 Solana 成交的剩余仓位为同币 SPL 账户与原生 SOL 合计；跨链成交读取平台余额索引；它是确认后读取时的余额，可包含其他交易变化，不是由旧持仓推算，也不等于严格成交瞬间余额。只读余额查询失败显示“未获取”，不虚构零；历史记录缺失字段显示未记录。报价、价格触达、已提交和未知结果都不会通知成交。
- 告警通知：登录凭据失效或 FOMO 接口调用失败；同类告警五分钟内去重。

留空不发送；两条通道不相互回退，不读取旧地址，也不补发未配置期间的通知。只接受 `https://open.feishu.cn/open-apis/bot/v2/hook/...`，不支持需要额外加签密钥的机器人。业务返回非零码也算失败，失败记录到日志，不递归发送告警。发送超时或后台中断可能导致通知结果未知，不自动重发成交消息，以免重复。

Webhooks 保存在当前扩展本地数据库，不发送到 FOMO，也不进入订单／日志导出。清空输入并保存即可关闭对应通道。`config/local.example.json` 仅说明数据结构，不是运行配置加载入口。

## 刷新与恢复

刷新按钮自动发现当前窗口的 FOMO 页；接收脚本失效时刷新对应页并清除旧快照。页面加载中避免重复刷新；没有 FOMO 页时提示打开并登录。

订单和配置存储于当前 Chrome 配置目录；清除扩展数据或卸载会影响本地记录。重开后等待账户与新鲜行情，不能用旧价格补交易。实际浏览器退出恢复和长期后台可靠性仍待验收。

## 交易状态

准备 → 签名 → 保存哈希 → 提交 → 链上核对 → 成交／失败。交易详情链接按来源网络打开相应区块浏览器。跨链另核对平台状态与精确关联的真实成交索引；仅来源链上链不代表目标币到账。关闭真实下单或自动监控会中止未提交的执行，但不能撤销已广播的交易；已提交交易继续查询结果。

后台重启时，准备中的交易标记失败，不重新提交；已签名或已提交的记录转为待核对，只查既有哈希／Relay 请求 ID／Mobula intent ID／UserOperation 哈希。跨链缺少实际交易关联或成交数量索引时继续待核对，不以预期报价替代成交；附带保护与成交通知也会等待。未知交易会阻止本账户的新交易，避免重复花费；当前没有自动解除未知状态的按钮，请先通过链上记录核对，不能重复建单绕过。
