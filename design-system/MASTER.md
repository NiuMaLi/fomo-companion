# FOMO Companion 界面规范

适用：React Chrome 侧边栏，约 320–520px，中文单账户交易工作台。

ui-ux-pro-max 检索匹配到深色金融配色，但两次返回的 Enterprise Gateway 营销页结构均不适用于侧边栏，未采用。布局依据技能通用准则自行设计：状态、行情、监控开关、导航、当前任务，保留键盘焦点和减少动态效果支持。

- 深色绿灰底、青绿实时状态、浅黄绿主操作；红色用于卖出与错误，必须同时有文本。
- 使用系统中文字体，不请求在线字体；金额采用 tabular-nums。
- Lucide 同系列图标；产品字标为文字，不使用外部交易所 Logo 资产。
- 设置与状态和订单录入分开；仅展示真实账户持仓；真实下单状态清晰可见。
- 明确展示断线、未登录、行情过期、未支持能力；不以演示数据填充真实账户。
- UI 不包含 Token 输入框，也不展示 SDK、消息通道或数据库细节。
