# FOMO Companion

**简体中文** | [English](README.en.md)

用于 [FOMO](https://fomo.family) 的 Chrome 浏览器扩展，提供真实账户持仓、实时行情、限价条件单、止盈止损、交易日志和飞书通知。

基于 WXT、React、TypeScript 和 Manifest V3。支持中文与 English，当前版本 **v0.8.0**。

> 本项目为非官方扩展，依赖 FOMO 当前网页接口和钱包能力。真实执行入口已实现，但各网络的完整实盘买卖、长期值守和浏览器退出恢复尚未完成验收。请先阅读执行说明与测试记录。

## 功能

- **账户与持仓**：读取当前登录账户，展示代币头像、真实数量、平均买入价和未实现盈亏。
- **实时行情**：跟随当前 FOMO 代币页面；每笔待执行条件单独立订阅自身资产的行情，切换当前 K 线不会改变旧订单资产。
- **图表选价**：点击 FOMO 主价格 K 线回填目标价格，并显示相对现价／成本的涨跌幅。
- **条件单**：限价买入、限价卖出、止盈卖出、止损卖出；支持 30%／50%／100% 和自定义卖出比例。
- **附带止盈止损**：限价买入时设置保护计划，买入确认后按本笔实际买入数量创建互斥卖单。
- **逐单滑点**：最大滑点可选填，空值或 0 关闭插件滑点保护，不使用默认值；附带保护单继承父单配置。
- **真实执行开关**：关闭时仅保存并记录价格触达，不报价、不签名、不广播，不生成模拟成交或持仓。
- **订单与日志**：本地持久保存，支持分类筛选、订单事件快照、完整交易哈希和脱敏 JSON 导出。
- **飞书通知**：订单成交通知与系统告警分别配置 Webhook；未配置不发送。
- **中英文切换**：保存语言偏好，界面、历史日志显示和新发送的飞书消息跟随切换。

适配 FOMO 当前的 Ethereum、BNB、Monad、Robinhood、Arc、Base、Solana 现货网络，按平台可用报价与原生路线执行。平台可能因余额、流动性、交易金额、网络或钱包状态拒绝交易；网络支持不代表任意代币都能成交。

## 安装

### 从发布包安装

1. 获取项目发布的 Chrome ZIP 并解压，确认目录中包含 `manifest.json`。
2. 打开 `chrome://extensions`，开启“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择解压后的目录。
4. 打开并登录 FOMO，刷新页面后，点击扩展图标打开侧边栏。

当前采用手动加载方式，未提供 Chrome Web Store 安装链接。

### 从源码构建

需要 **Node.js 22.12+**、npm，以及支持 Side Panel 的 **Chrome 116+**。Node.js 版本要求同时取决于锁文件中的构建工具。

克隆仓库并进入项目根目录后执行：

```bash
npm ci
npm run build
```

在 Chrome 中加载 `.output/chrome-mv3`。执行 `npm run zip` 可生成 `.output/fomo-companion-0.8.0-chrome.zip`。

更新时覆盖原安装目录并在扩展管理页重新加载，随后刷新 FOMO 页面。避免卸载重装；卸载或清除扩展数据可能导致本地订单、日志和配置丢失。

## 使用

1. 在 FOMO 打开需要交易的代币详情页，等待侧边栏的账户与行情连接就绪。
2. 在“交易”页选择订单类型，输入目标价格、买入金额或卖出比例。也可点击 K 线带入价格。
3. 按需填写最大滑点，或为限价买入附带止盈止损，然后保存条件单。
4. 如需自动提交交易，在钱包能力就绪后开启“设置 → 真实下单”，再开启自动监控。
5. 在“条件单”查看状态，在“日志”展开事件对应的订单详情。

### 执行与恢复

- **Chrome 和至少一个已登录、可用的 FOMO 执行页面必须保持运行。** 关闭浏览器、关闭执行页面、电脑休眠或连接失效时，条件单不能继续执行。目前没有独立服务器执行能力。
- 订单、日志、配置保存在扩展本地 IndexedDB。重开后等待账户及新鲜行情恢复，不使用旧价格补交易。
- 价格触达、报价或交易提交均不代表成交；只有实际成交核对成功才标记成交、启用附带保护及发送成交通知。
- 关闭真实下单或监控可中止后续提交，不能撤销已广播交易；已提交的交易继续核对结果。
- 结果未知时保留原交易标识并持续核对，避免重复下单。不要通过重复建单绕过待核对状态。
- 网站钱包可能要求人工签名／验证；网页登录状态和签名能力不保证长期可用。

### 滑点与保护单

最大滑点在每笔条件单中独立配置，允许大于 0 且不超过 5%，步进为 0.01%。**留空或 0 不启用插件滑点保护**，不回退旧全局配置，也不向平台传自定义滑点参数。平台构建的交易仍可能包含其自身最小输出等限制；插件不改写已签名交易。

启用滑点时按包含滑点的保守报价检查限价／止盈目标，止损检查相对实时价格的偏离；关闭时限价／止盈仍检查预期报价是否满足目标，止损不做额外报价偏离上限检查。独立的 5% 价格影响校验保留。目标价不保证实际成交价。

附带止盈止损按本笔实际买入数量计算，向下按代币精度取整。一侧成交后另一侧取消，**即使只卖出 30% 也会取消另一侧**；剩余仓位需要另行设置。父买单未成交、失败或取消时，不启用子单。

插件没有固定 SOL 币种、2U 最低交易额或 10U 持仓上限。交易仍须满足平台规则、代币精度、真实余额及防超卖校验；开发实盘测试策略单独记录，不是产品限制。

### 飞书通知

在“设置 → 飞书通知”分别填写并保存两个自定义机器人 Webhook：

| 通道 | 发送内容 |
| --- | --- |
| 订单通知 | 已确认成交的币对、方向、价格、数量、价值、确认核对时剩余仓位、订单编号与交易哈希 |
| 告警通知 | 登录凭据失效、接口调用失败等系统异常，同类告警有冷却去重 |

地址为空时不发送，两个通道不互相回退，不补发未配置期间的消息。当前支持飞书自定义机器人 Webhook，不支持额外加签密钥配置。余额无法核对时显示未知，不伪造为零。

通知时间跟随运行扩展的系统时区，并标注时区偏移（例如 `2026-10-21 07:30:00 GMT+08:00`）；中英文切换不改变时区。成交通知显示成交确认时间，告警通知显示告警发生时间。

Webhook 直接在插件中配置。`config/local.example.json` 仅说明设置结构，**不会被自动加载**。

## 开发

```bash
npm ci
npm run dev        # WXT 开发模式
npm run typecheck  # TypeScript 检查
npm test           # Vitest 确定性测试
npm run build     # Chrome 生产构建
npm run zip       # 生成分发 ZIP
```

自动化测试使用合成数据和 mock，无需 FOMO 登录、真实资金或飞书 Webhook。覆盖行情隔离、订单预留、逐单滑点、互斥保护、执行防重、成交核对、数据库兼容、通知、日志与国际化。

浏览器探针位于 `scripts/`，属于开发诊断工具，不是常规测试或扩展运行依赖。运行前阅读脚本及[验证记录](docs/fomo/VERIFICATION.md)，只对专用测试标签页操作。真实签名、广播和通知验收应单独授权并遵循测试策略。

### 目录结构

```text
entrypoints/          扩展后台、内容脚本与侧边栏入口
src/
  components/         React 界面与样式
  i18n/               英文词条
  shared/             数据模型、协议、网络及通用逻辑
  storage/            IndexedDB、日志与历史数据兼容
  trading/            条件单、报价、签名、执行与成交核对
  notifications/      飞书通知
config/               不含凭据的配置与实盘测试策略示例
tests/               确定性测试
scripts/              开发诊断工具
docs/                 使用、架构、接口与验证文档
design-system/        界面规范
```

### 提交与协作

提交源码、测试、文档、配置示例和 `package-lock.json`；不提交 `node_modules/`、`.wxt/`、`.output/` 等生成目录。发布 ZIP 可作为仓库 Release 附件分发。

新增功能或修复时，请运行类型检查、测试及生产构建；涉及交易执行时补充防重复提交、关闭开关、失败／未知状态和恢复行为的验证。报告问题时附扩展版本、Chrome 版本、复现步骤及脱敏错误，不提交 Token、Cookie、Webhook、钱包私密材料或完整账户导出。

`.gitignore` 已排除常见本地配置、日志、交易导出、浏览器网络抓包及密钥文件。它只对未跟踪文件生效；已经提交过的文件需要单独停止跟踪，历史中的敏感信息也不会因添加忽略规则自动消失。
